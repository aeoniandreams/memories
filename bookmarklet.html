대화 캡처 북마클릿

아래 두 버튼을 브라우저 북마크바로 드래그해서 등록하세요. (클릭이 아니라 드래그입니다)

코드 준비 중...

① 캡처 시작 ② 캡처 완료

사용 순서

1. X에서 백업하고 싶은 대화(스레드/DM)를 엽니다.
2. 북마크바의 ① 캡처 시작을 클릭합니다.
3. 대화 끝까지 천천히 스크롤합니다. (스크롤하는 동안 자동으로 계속 인식됩니다)
4. 끝까지 내렸으면 ② 캡처 완료를 클릭합니다. → 대화 내용이 클립보드에 복사됩니다.
5. memories 앱을 열고 "새 대화 추가" → 붙여넣기 → 불러오기 → 확인 후 저장.

드래그가 안 될 때

북마크를 하나 새로 만든 뒤(주소 아무거나), 편집 화면에서 URL 칸에 아래 코드를 붙여넣어도 됩니다.
